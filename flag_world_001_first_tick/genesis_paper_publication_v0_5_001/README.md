## Rendering

`build_publication.py` is a document-production utility, not part of the MaL execution path. It requires ReportLab, pypdf and the host's licensed Georgia, Segoe UI, Consolas and Cambria fonts. Font files are not distributed. Run it from any directory to regenerate the PDF and build record; the promoted source hash is checked before rendering.

The PDF was rendered to images and all eight pages inspected for layout, equations, tables, headers, footers and references. Temporary page images are excluded from the release.
