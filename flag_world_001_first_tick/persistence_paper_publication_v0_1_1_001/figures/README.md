# Paper Two figures

Publication plotting from sealed compact evidence. No engine, native GPU or world-transition work.

- Figure 1: the (4,0) adjacent-pair classification and distinct GPU receipt scope.
- Figure 2: the same-hole context contrast, with receipt categories shown separately.
- Figure 3: single-site and nested-field refinement correspondences.
- Cover: 1200 x 630 pixels for Substack/social preview.

Each figure has a vector SVG, a 300-DPI PNG and a web PNG. Captions and alt text are in CAPTIONS_AND_ALT.md; figuredata.json binds source hashes and data pointers.

Reproduce using Python with matplotlib and NumPy: `python render_figures.py --evidence-dir /path/to/companion/evidence`. Outputs are written beside the script. Plot generation is document work only. A rerun resets visual review to PENDING; readback and visual review remain separate.
